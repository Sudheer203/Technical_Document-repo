# Django ORM – Converting ORM Queries to SQL in Django Shell

## 1. Introduction

Django provides an **Object Relational Mapper (ORM)** that allows developers to interact with the database using **Python code instead of writing SQL queries**.

However, sometimes developers want to see the **actual SQL query generated by Django ORM**.

This can help with:

* Understanding how ORM works
* Debugging queries
* Optimizing database performance
* Learning SQL from ORM queries

Django makes it possible to **view the SQL generated by ORM queries directly in the Django Shell**.

---

# 2. Starting Django Shell

To use ORM queries, open the Django shell using:

```bash
python manage.py shell
```

This opens an **interactive Python environment** connected to your Django project.

---

# 3. Importing Models

Before running queries, import the model you want to use.

Example:

```python
from students.models import Student
```

Now the `Student` model can be used for ORM queries.

---

# 4. Basic ORM Query Example

Example ORM query:

```python
Student.objects.filter(age=20)
```

This retrieves all students whose age is 20.

But this query is written in **Python**, not SQL.

---

# 5. Viewing SQL from ORM Query

To see the SQL query generated by Django, use:

```python
print(Student.objects.filter(age=20).query)
```

Example output:

```sql
SELECT "students_student"."id",
       "students_student"."name",
       "students_student"."age"
FROM "students_student"
WHERE "students_student"."age" = 20;
```

This is the **actual SQL query sent to the database**.

---

# 6. Another Example

### ORM Query

```python
Student.objects.filter(age__gt=18)
```

### View SQL

```python
print(Student.objects.filter(age__gt=18).query)
```

### SQL Output

```sql
SELECT * FROM students_student
WHERE age > 18;
```

---

# 7. Example with Multiple Conditions

### ORM Query

```python
Student.objects.filter(age=20, name="Sudheer")
```

### SQL Query

```python
print(Student.objects.filter(age=20, name="Sudheer").query)
```

### SQL Output

```sql
SELECT * FROM students_student
WHERE age = 20 AND name = 'Sudheer';
```

---

# 8. Viewing SQL for Ordering

### ORM Query

```python
Student.objects.order_by("age")
```

### SQL Query

```python
print(Student.objects.order_by("age").query)
```

### SQL Output

```sql
SELECT * FROM students_student
ORDER BY age ASC;
```

---

# 9. Viewing SQL for Limiting Results

### ORM Query

```python
Student.objects.all()[:5]
```

### SQL Query

```python
print(Student.objects.all()[:5].query)
```

### SQL Output

```sql
SELECT * FROM students_student
LIMIT 5;
```

---

# 10. Why Converting ORM to SQL is Useful

Developers often inspect SQL queries to:

* Debug database issues
* Improve query performance
* Understand how Django translates Python code into SQL
* Learn database optimization techniques

It is especially useful when working with **complex ORM queries**.

---

# 11. Best Practices

When analyzing ORM-generated SQL:

* Avoid unnecessary queries
* Use `select_related()` and `prefetch_related()` to optimize joins
* Monitor database queries during development
* Ensure indexes exist for frequently filtered fields

---

# 12. Conclusion

Django ORM simplifies database interactions by allowing developers to write **Python code instead of SQL**.

However, Django also provides tools to inspect the **actual SQL queries generated by the ORM**.

Key points:

* Use Django Shell for testing ORM queries
* Use `.query` to display SQL generated by ORM
* Understanding SQL helps optimize database performance

This knowledge helps developers build **efficient and scalable Django applications**.
